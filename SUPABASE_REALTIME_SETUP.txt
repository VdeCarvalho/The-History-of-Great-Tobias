THE HISTORY OF GREAT TOBIAS — SUPABASE REALTIME SETUP

WHAT THIS ENABLES
-----------------
- Global usernames across devices.
- Global chat across devices.
- Real-time new messages via Supabase Realtime.
- The newest 1,000 chat messages remain in the database.
- Deleting a character does NOT delete their old chat messages.

STEP 1 — CREATE A SUPABASE PROJECT
----------------------------------
Create/open a Supabase project.

STEP 2 — RUN THE DATABASE SETUP
-------------------------------
Open Supabase SQL Editor and run the complete file:

  SUPABASE_SETUP.sql

It creates/updates:
- players
- chat_messages
- username helper functions
- username release function
- 1,000-message pruning trigger
- Realtime publication for chat_messages

STEP 3 — COPY TWO PUBLIC VALUES
--------------------------------
In Supabase, copy:
1. Project URL
2. Publishable key (sb_publishable_...)

Do NOT use a secret key or service_role key in a web page.

STEP 4 — EDIT backend-config.js
-------------------------------
Fill:

window.TOBIAS_BACKEND = {
  mode: "supabase",
  supabaseUrl: "https://YOUR-PROJECT.supabase.co",
  supabasePublishableKey: "sb_publishable_...",
  supabaseAnonKey: "",
  maxSuffix: 99999
};

STEP 5 — UPLOAD TO GITHUB PAGES
--------------------------------
Upload/replace all files from this package.
